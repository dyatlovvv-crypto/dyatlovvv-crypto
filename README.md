# dyatlovvv-crypto

Приложения **SpustyaRukovaRecords** — Android-утилиты, VPS cockpit и снег на рабочем столе.

## Приложения

| Приложение | Что делает | Платформа |
| --- | --- | --- |
| [contexto](https://github.com/dyatlovvv-crypto/contexto-releases) | Inbox: сохрани сейчас, разберись потом | Android, macOS |
| [ebook-reader](https://github.com/dyatlovvv-crypto/ebook-reader) | Читалка EPUB / FB2 / TXT | Android |
| [autolog](https://github.com/dyatlovvv-crypto/autolog) | Журнал расходов на авто | Android |
| [browser](https://github.com/dyatlovvv-crypto/browser) | Браузер в духе Safari | Android |
| [notes](https://github.com/dyatlovvv-crypto/notes) | Заметки | Android |
| [passwords](https://github.com/dyatlovvv-crypto/passwords) | Менеджер паролей | Android |
| [vps-cockpit](https://github.com/dyatlovvv-crypto/vps-cockpit) | SSH-туннель до Cockpit с Matrix Core UI | Desktop / VPS |
| [Snowpuff](https://github.com/dyatlovvv-crypto/Snowpuff) | Снег на рабочем столе: ложится на окна, смахивается курсором | macOS, Windows |

## Заметки
